# あしあとダンジョン（仮）

不思議のダンジョン再構築の試作。アイテム欄をなくし、スキルとパッシブで潜る。
スキルは「歩数」で自動発動し、敵も同じ仕組みで、発動までの残り歩数が見える。
床には足跡や血痕（痕跡）が残る。
